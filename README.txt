KNICKOSH FEDERIS PORTFOLIO
==========================

FILES
  index.html                          all pages (Home, About, Skills, Experience, Projects, Education, Contact)
  style.css                           all styles (colors are at the very top, under :root)
  script.js                           page transitions, animations, tabs, theme switch, contact form
  contact.php                         contact form handler (needs PHP hosting such as InfinityFree)
  .htaccess                           speed + security settings
  assets/img/knickosh.jpg             your photo
  assets/Knickosh-Federis-Resume.pdf  resume download button

UPLOAD (InfinityFree)
  1. Control Panel > Online File Manager (or FTP with FileZilla) > open htdocs.
  2. Delete the old files (index2.html and the old css/js folders).
  3. Upload everything INSIDE this folder so index.html is directly in htdocs.
  4. Open your domain, then press Ctrl+Shift+R to refresh the cache.

TEST ON YOUR COMPUTER
  Just double-click index.html. (The contact form only sends once it is on PHP hosting;
  until then it offers a "Send it with your email app" link.)

EDITING TIPS
  - Colors:  style.css, top of file (:root = dark theme, html[data-theme="light"] = light theme)
  - Text:    index.html
  - Photo:   replace assets/img/knickosh.jpg (portrait, ratio about 5:8 looks best)
  - Resume:  replace assets/Knickosh-Federis-Resume.pdf with your latest PDF (same name)
  - Project links: in index.html, search "See my GitHub" and change the href to the repo link

NAVIGATION
  Click a menu button, use the arrow keys, press 1-7, or swipe left/right on a phone.
